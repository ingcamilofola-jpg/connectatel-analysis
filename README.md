# 📊 Análisis ConnectaTel

Análisis de comportamiento de clientes de una empresa de telecomunicaciones en Latinoamérica.

## 🎯 Objetivo
Explorar, limpiar y analizar datos de clientes para identificar patrones de uso, detectar comportamientos atípicos y crear segmentos de clientes.

## 📂 Datasets utilizados
- `plans.csv` → planes disponibles (precio, minutos, GB)
- `users_latam.csv` → información de clientes
- `usage.csv` → detalle de llamadas y mensajes

## 🔄 Etapas del análisis
1. Carga y exploración de datos
2. Identificación de problemas de calidad
3. Limpieza de datos
4. Estadísticas por usuario
5. Visualizaciones y outliers
6. Segmentación de clientes
7. Insight ejecutivo

## ▶️ Cómo ejecutar
Abre el notebook en Google Colab con el botón **Open in Colab** y sube los 3 archivos CSV.

## 🛠️ Herramientas
Python, pandas, numpy, seaborn, matplotlib
